Exact polarized recursive decomposition of finite scalar expressions: nonnegative convex monotone heads on independent nonnegative doubled inputs, and globally convex nonnegative heads after the canonical signed-input split. Applies to multiplicative ReLU computations; matrices and convolutions reduce to scalar sums/products and finite maxima to ReLU. No size bound or floating-point guarantee is asserted.

13/-- Combined contract of the existing polarized algorithm, valid at every finite
14expression depth, on independent nonnegative input pairs and on raw signed inputs. -/
15theorem polarized_expression_dc {ι : Type u} (e : Expr ι) :
16    Regular (Ici (0 : DoubledInput ι)) e.decompose ∧
17    (∀ x : DoubledInput ι,
18      (e.decompose x).1 - (e.decompose x).2 = e.eval (x.1 - x.2)) ∧
19    ConvexOn ℝ univ (fun x : ι → ℝ => (e.rawDecompose x).1) ∧
20    ConvexOn ℝ univ (fun x : ι → ℝ => (e.rawDecompose x).2) ∧
21    (∀ x : ι → ℝ, 0 ≤ e.rawDecompose x) ∧
22    (∀ x : ι → ℝ,
23      (e.rawDecompose x).1 - (e.rawDecompose x).2 = e.eval x) := by
24  exact ⟨e.decompose_regular, e.decompose_exact,
25    e.rawDecompose_convex.1, e.rawDecompose_convex.2,
26    e.rawDecompose_nonnegative, e.rawDecompose_exact⟩
